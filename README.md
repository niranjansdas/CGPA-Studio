
# CGPA Studio

**A desktop-based academic performance management application built with Python.**

CGPA Studio helps students calculate, monitor, analyse and predict their academic performance through a simple desktop interface.

## Current Version
**v0.7**

## Features

- SGPA calculation based on subject credits and grade points.
- Cumulative CGPA calculation across semesters.
- Add, edit and delete subjects.
- Multi-semester academic record management.
- SQLite database integration for persistent storage.
- Academic performance analytics and semester comparisons.
- SGPA and CGPA progression charts.
- Grade distribution analysis.
- CGPA prediction and target planning.
- Maximum possible CGPA calculation.
- Projected final CGPA based on current performance.
- Database backup and restoration.

## Technology Stack

- Python
- Tkinter
- SQLite
- Matplotlib (if used in the analytics implementation)

## Installation

### Run from source

1. Install Python.
2. Download or clone this repository.
3. Install the required dependencies.
4. Run:

```bash
python main.py
```

### Windows Application

A standalone Windows executable is available under the Releases section.
