
# CGPA Studio

A desktop-based academic performance calculator built using Python and Tkinter.

## Features

- Calculate SGPA using subject credits and grade points.
- Add, edit and delete subjects.
- Automatically recalculate SGPA.
- Validate user inputs.

## Technology Stack

- Python
- Tkinter

## Current Version

0.2.1

## Future Development

- Multi-semester management.
- Cumulative CGPA calculation.
- SQLite database integration.
- Academic performance dashboard.
